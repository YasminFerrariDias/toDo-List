# Lista de Tarefas

Lista de tarefas desenvolvida com React, TypeScript e Vite, com foco em componentização e tipagem estática. Projeto em desenvolvimento.

## Tecnologias

- [React](https://react.dev/) — biblioteca para construção de interfaces
- [TypeScript](https://www.typescriptlang.org/) — tipagem estática
- [Vite](https://vitejs.dev/) — bundler e servidor de desenvolvimento

## Como Executar

```git clone https://github.com/YasminFerrariDias/todo-list.git```

```npm install```

```npm run dev```
